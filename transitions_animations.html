Navigation Transition

I used a CSS animations transition on the navigation header. When the user moves the cursor to one of the headers it changes its background and font colour and moves up a bit.

Image Fade-In Animation

I used a CSS animation on the images in my website. When the page loads, the image gradually appears using a fade-in effect.
